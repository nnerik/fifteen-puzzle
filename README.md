## Fifteen Puzzle

This is a toy project implementing the 15-puzzle using TypeScript, React, SVG, and CSS animations. You can try the three by three version, also known as the 8-puzzle, at my [GitHub Pages](https://nnerik.github.io/fifteen-puzzle/ "Fifteen Puzzle (3x3)").

### Development

This project uses [mise](https://mise.jdx.dev/) for tool versions and pnpm for dependencies.

```sh
mise install
pnpm install
pnpm dev
```

Useful scripts:

```sh
pnpm test
pnpm typecheck
pnpm build
pnpm preview
```
